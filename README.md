# Python_Love_Calculator
# Love Calculator (TRUE Method)

A small Python script that estimates a "love score" between two names using
the classic T-R-U-E letter-counting method.

## How it works

The script combines both names, converts them to lowercase, and counts how
many times each letter of the word `TRUE` appears across the combined name.

## Usage

```python
calculate_love_score(name1="Angela", name2="Jack Bauer")
```

Example output:

T occurs 1 times

R occurs 1 times

U occurs 1 times

E occurs 2 times

## Notes

This is a simplified take on the classic playground "FLAMES"/love-calculator
